# Foodie Website 🍔🍕

A simple and responsive food delivery landing page built using **HTML** and **CSS**.

## 📌 Features

* Responsive navigation bar
* Hero section with food banner
* Search section for location and categories
* Browse food categories
* Featured restaurants section
* Promo offers section
* Customer testimonials
* App download section
* Footer with contact and social links

## 🛠 Technologies Used

* HTML5
* CSS3

## 🚀 How to Run

1. Download or clone this repository
2. Open the project folder
3. Open `index.html` in your browser

## 🎯 Purpose

This project was created for practice to improve frontend development skills and build a clean landing page UI.
